This is a simple dashboard created using Java and Swing and can be viewed by running Main.java. 

The dashboard should look something like this: https://imgur.com/a/IkCEGaV

Swing was chosen as the prime GUI/visualization as it is already integrated in Java and though alternative frontend tools exist, Swing is perfect for a simple exercise such as this.

The 3 key data visualizations chosen Missions by Company, Status Breakdown, and Launches by Year.

The justifications are as followed:

Missions by Company: Compared to other space programs, the Soviet space program have a predominant number of missions at a staggering 1777 launches.

Status Breakdown: This visualization illustrates that in general, there is roughly a 10% chance of failure for rocket launches.

Launches per year: This visualization shows a trend where there was an increasing number of launches in 2020 which is perhaps explained by the rise of private space companies such as SpaceX.
